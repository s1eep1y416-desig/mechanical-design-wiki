# 工程图解库

从装配结构到受力路径，按知识点查阅 **82 张独立教学图解**。覆盖十八章和三个基础专题；每张图都在对应章节内出现，也可在这里搜索、放大查看。全部图解均可下载 SVG，适合放大阅读。

## 图解的使用范围

63 张结构与原理图、8 张受力分析图和11张关系曲线按独立知识点计数，共82张；不包含图标、首页重复图、图解库的重复展示和配合交互组件。结构图为独立绘制的教学示意，放大的间隙、局部剖面及省略部件均以图注说明，不能直接作为加工或选型依据。

- 齿轮渐开线、基圆与尺寸关系参照 [KHK 齿轮技术资料](https://khkgears.net/new/gear_knowledge/gear_technical_reference/calculation_gear_dimensions.html)，齿根过渡采用教学近似。
- 轴承配置和定位原则参照 [NSK 轴承配置技术说明](https://www.nsk.com/content/dam/nsk/eu/en_gb/documents/bearings-europe/P_TI-0104_EN.pdf)。压力线示意用于比较支点距离，不替代具体产品内部几何。
- 链条图采用相等销轴中心距生成闭合链；滚子座为圆弧，齿顶过渡仍为示意。
- 受力分析需同时阅读研究对象、转向、单位和适用条件；曲线图中的定性趋势不应当作材料或产品试验数据。
