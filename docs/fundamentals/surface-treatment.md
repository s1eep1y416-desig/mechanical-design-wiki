# 表面处理

<p class="topic-lead">
机械零件的失效往往从表面开始：腐蚀、磨损、点蚀、疲劳裂纹，都发生在最外层几微米到几毫米。表面处理不是“最后刷一层”，而是设计阶段就要确定的表面工程。

<UnitConvention note="镀层/渗层厚度用 μm；温度用 °C；盐雾时间用 h；摩擦系数、效率无量纲。" />
</p>

::: info 表面处理与表面热处理的区别
**表面处理**主要改变表面成分、组织或覆盖层，例如电镀、阳极氧化、磷化、喷涂；**表面热处理**主要改变表层组织与硬度，例如感应淬火、渗碳、渗氮。两者可以组合使用。
:::

## 1. 表面处理解决什么问题

| 目标 | 典型手段 | 设计关注点 |
| --- | --- | --- |
| 耐腐蚀 | 镀锌、热浸镀锌、阳极氧化、涂装 | 镀层完整性、孔隙、电偶腐蚀 |
| 耐磨 | 硬铬、化学镀镍、PVD/DLC、热喷涂 | 硬度、厚度、结合力、对偶件磨损 |
| 减摩 | 磷化、二硫化钼、PTFE 涂层 | 磨合性、润滑剂相容性 |
| 提高疲劳强度 | 喷丸、滚压 | 残余压应力、表面粗糙度 |
| 装饰 | 电镀、阳极氧化、涂装 | 颜色、光泽、均匀性 |
| 绝缘/导电 | 阳极氧化、导电镀层 | 厚度、电阻、接触电阻 |

## 2. 常见表面处理工艺

| 工艺 | 典型厚度 | 主要作用 | 适用材料 | 设计注意 |
| --- | --- | --- | --- | --- |
| 电镀锌 | 5–25 μm | 牺牲阳极保护，耐大气腐蚀 | 钢、铸铁 | 高强度钢注意氢脆；螺纹和配合要留量 |
| 热浸镀锌 | 45–85 μm | 厚锌层，户外耐蚀 | 钢构件 | 温度高、可能变形；螺纹需清理 |
| 电镀硬铬 | 10–50 μm | 耐磨、修复尺寸 | 钢、铸铁 | 边缘镀层堆积；氢脆；深孔难镀 |
| 化学镀镍 | 10–50 μm | 均匀耐蚀、耐磨 | 钢、铜、铝 | 镀液维护；结合力和内应力 |
| 阳极氧化 | 5–25 μm | 铝表面耐蚀、绝缘、装饰 | 铝合金 | 尺寸会增长；需封孔；颜色批次差 |
| 磷化 | 2–20 μm | 涂装底层、磨合、防锈 | 钢、铸铁 | 多孔，需后处理；耐蚀有限 |
| 发黑/氧化 | 小于 2 μm | 轻微防锈、装饰 | 钢 | 尺寸变化小；需涂油 |
| 钝化 | 小于 1 μm | 恢复不锈钢/镀锌层钝化膜 | 不锈钢、锌层 | 不能修复严重划伤 |
| 热喷涂 | 0.1–数 mm | 耐磨、耐蚀、修复 | 钢、铸铁 | 孔隙率、结合强度、后续加工 |
| PVD/CVD | 1–10 μm | 硬质耐磨、低摩擦 | 钢、硬质合金 | 视线遮挡、温度限制、边缘结合 |
| 喷丸 | 不增厚 | 引入残余压应力，提高疲劳强度 | 钢、铝、钛 | 覆盖率、丸粒尺寸、表面完整性 |
| 涂装 | 20–200 μm | 防腐、装饰、绝缘 | 大多数材料 | 前处理、附着力、针孔、固化 |

::: warning 不是越厚越好
镀层过厚会增加脆性、降低结合力、改变配合间隙；渗层过深也可能让表层过脆。厚度必须与载荷、配合、加工余量和失效模式匹配。
:::

## 3. 怎么选表面处理

按下面的顺序判断，而不是先选工艺：

1. **基材**：钢、铝、不锈钢、铸铁，能接受的工艺不同；
2. **环境**：室内、户外、潮湿、盐雾、酸碱、高温；
3. **失效模式**：均匀腐蚀、点蚀、磨粒磨损、黏着磨损、接触疲劳；
4. **尺寸与配合**：镀层是否影响螺纹、轴承配合、密封面；
5. **疲劳与氢脆风险**：高强度钢、承受交变载荷的零件；
6. **批量与成本**：挂镀、滚镀、连续线、手工喷涂；
7. **后处理**：钝化、封孔、涂油、烘烤去氢。

### 常用组合

- 钢制紧固件：镀锌 + 钝化；高强度螺栓优先考虑机械镀锌或达克罗，并评估氢脆；
- 钢制液压杆：镀硬铬 + 抛光；注意边缘和氢脆；
- 铝合金外壳：阳极氧化 + 封孔；
- 钢制齿轮箱内壁：磷化 + 涂装，或直接耐油涂层；
- 刀具/模具：PVD 硬质涂层；
- 大型钢结构：热浸镀锌或重防腐涂装；
- 弹簧/连杆：喷丸 + 发黑/涂装，优先提高疲劳强度。

## 4. 结构设计要点

### 镀层与配合

电镀层会改变实际尺寸。设计时要明确：

- 镀前尺寸还是镀后尺寸？
- 螺纹、键槽、轴承配合、密封面是否要遮蔽？
- 内孔镀层厚度是否足够、是否均匀？
- 镀后是否还要磨削或铰孔？

一般原则：**配合面、螺纹和精密表面优先镀前留量或局部遮蔽**，不要指望镀层自然均匀。

### 边缘与尖角

电镀时边缘电流密度高，镀层容易堆积、烧焦或起皮；尖角还会造成应力集中。设计时应倒圆、倒角，避免尖锐边缘直接受镀。

### 氢脆

高强度钢在酸洗、电镀过程中可能吸收氢，装配后延迟断裂。措施：

- 避免高强度钢使用酸性电镀，优先机械镀、无氢工艺；
- 电镀后及时烘烤去氢；
- 控制酸洗时间，避免过度腐蚀；
- 重要零件进行氢脆试验或延迟断裂评估。

### 盲孔与缝隙

盲孔、缝隙容易残留镀液，造成腐蚀或渗氢。应设置排液孔、通气孔，避免窄缝；焊接件要清理焊渣和封闭空腔。

### 电偶腐蚀

两种电位不同的金属接触，在潮湿环境中会形成电偶。设计时：

- 避免小阳极/大阴极面积比；
- 用绝缘垫、涂层隔开异种金属；
- 选择牺牲阳极性镀层保护基体；
- 注意紧固件与基材的电位差。

### 疲劳

硬镀层可能降低疲劳强度，喷丸、滚压等压缩残余应力工艺可提高疲劳强度。承受交变载荷的轴、弹簧、连杆要同时评估表面处理对疲劳的影响。

## 5. 常见失效与对策

| 失效 | 原因 | 设计/工艺对策 |
| --- | --- | --- |
| 镀层起皮、脱落 | 前处理不良、油污、氧化皮、结合力不足 | 彻底除油除锈，控制镀液和电流，做结合力试验 |
| 镀层孔隙、点蚀 | 镀层太薄、孔隙多、基体粗糙 | 增加厚度、抛光基体、双层镀、封孔 |
| 镀层不均 | 电流分布不均、深孔、边缘效应 | 优化挂具、辅助阳极、倒圆、遮蔽 |
| 氢脆断裂 | 高强度钢酸洗/电镀吸氢 | 低氢工艺、烘烤去氢、控制强度等级 |
| 螺纹/配合装不上 | 镀层厚度未留量 | 镀前留量、遮蔽、镀后过通规 |
| 磨损失效 | 镀层硬度/厚度不足、对偶件不匹配 | 提高硬度、选择耐磨涂层、控制接触应力 |
| 电偶腐蚀 | 异种金属接触、潮湿环境 | 绝缘、涂层、选择相容材料 |
| 疲劳强度下降 | 镀层脆性、残余拉应力、表面缺陷 | 喷丸、优化镀层、避免尖锐缺口 |

## 6. 检验与标准

常见检验项目：

- 外观与颜色；
- 镀层厚度（磁性法、涡流法、金相法、库仑法）；
- 结合力（划格、弯曲、热震）；
- 耐蚀性（中性盐雾试验）；
- 氢脆（延迟断裂试验）；
- 表面粗糙度与摩擦系数。

常见标准检索线索：

- 金属覆盖层 钢铁制件热浸镀锌层：GB/T 13912；
- 金属及其他无机覆盖层 钢铁制件锌电镀层：GB/T 9799；
- 工程用铬电镀层：GB/T 11379；
- 铝及铝合金阳极氧化：GB/T 8013 系列；
- 金属材料 维氏硬度试验：GB/T 4340.1。

::: warning 标准会更新
以上标准号仅用于检索，使用前必须在国家标准全文公开系统核对现行版本和适用范围。具体工艺参数应以供应商工艺文件和试验结果为准。
:::

## 7. 一个选型例子

一根 45 钢轴，轴承位在潮湿环境中发生微动磨损，要求不改变整体热处理状态。

可选方案：

1. **轴承位镀硬铬 15–20 μm**，镀后磨削到最终尺寸；
2. 螺纹、键槽和其余配合面**遮蔽**，避免镀层影响装配；
3. 镀前预留磨削余量，镀后检查直径和圆度；
4. 若轴为高强度钢，评估氢脆并按要求烘烤去氢；
5. 对磨削后的表面做粗糙度检查，避免镀层边缘堆积。

这个例子说明：表面处理不是单独的一道工序，而是和尺寸链、配合、热处理、装配一起设计的。
