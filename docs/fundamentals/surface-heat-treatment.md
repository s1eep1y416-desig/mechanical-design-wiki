# 表面热处理

<p class="topic-lead">
齿轮、轴、凸轮和模具常常需要“表面硬、芯部韧”。表面热处理通过改变表层组织，在不牺牲整体韧性的前提下提高耐磨性和接触疲劳强度。

<UnitConvention note="硬化层深度用 mm；硬度用 HRC 或 HV；温度用 °C；时间用 h；变形量用 mm 或 μm。" />
</p>

::: info 表面热处理不是表面处理
**表面热处理**改变的是表层组织与硬度，例如感应淬火、渗碳、渗氮；**表面处理**更多是覆盖层或转化膜，例如电镀、阳极氧化、磷化。两者的设计逻辑不同，但可以组合。
:::

## 1. 为什么要做表面热处理

| 需求 | 表面热处理的作用 |
| --- | --- |
| 齿面耐磨、抗点蚀 | 提高表层硬度，形成硬而耐磨的齿面 |
| 齿根抗弯 | 保留韧性好的芯部，避免整体淬硬变脆 |
| 轴颈耐磨 | 局部硬化，减少磨损和拉伤 |
| 抗胶合 | 提高表面硬度、降低摩擦系数 |
| 控制变形 | 只加热表层，减少整体淬火变形 |
| 提高疲劳强度 | 形成有利的残余压应力 |

表面热处理的核心参数不是“硬度越高越好”，而是**表面硬度、有效硬化层深度、芯部硬度与韧性、残余应力**之间的匹配。

## 2. 常见工艺

| 工艺 | 典型材料 | 有效层深 | 表面硬度 | 特点 |
| --- | --- | --- | --- | --- |
| 感应淬火 | 45、40Cr、42CrMo | 0.5–3 mm | 50–58 HRC | 局部加热、速度快、变形较小，需回火 |
| 火焰淬火 | 45、40Cr、铸钢 | 1–4 mm | 50–58 HRC | 设备简单，适合大型/单件，质量依赖操作 |
| 渗碳淬火 | 20Cr、20CrMnTi、18CrNiMo7-6 | 0.5–2 mm | 58–62 HRC | 表面高硬、芯部韧，周期长、变形较大 |
| 碳氮共渗 | 20CrMnTi、20Cr | 0.2–0.8 mm | 58–62 HRC | 温度较低、耐磨性好，需控制渗层组织 |
| 渗氮 | 38CrMoAl、40Cr、42CrMo | 0.1–0.5 mm | 900–1100 HV | 变形小、耐磨抗胶合，周期长、层浅 |
| 氮碳共渗（软氮化） | 45、40Cr、模具钢 | 0.01–0.2 mm | 500–700 HV | 温度低、变形小、抗咬合，承载层薄 |
| 激光/电子束淬火 | 45、40Cr、铸铁 | 0.2–1 mm | 50–60 HRC | 局部精确、变形小，设备成本高 |

::: warning 渗层深度不是越深越好
渗层过浅，接触疲劳和磨损会穿透硬化层；渗层过深，表层脆性增大、芯部韧性相对不足，可能发生剥落或开裂。深度要按接触应力、载荷性质和零件尺寸确定。
:::

## 3. 怎么选表面热处理

### 先看材料和载荷

- **低碳合金钢**：适合渗碳淬火，表面高硬、芯部韧；
- **中碳钢/中碳合金钢**：适合感应淬火、火焰淬火；
- **渗氮钢**：含 Al、Cr、Mo 的钢适合渗氮，如 38CrMoAl；
- **精密零件**：优先渗氮或氮碳共渗，变形小；
- **大型齿轮/单件**：感应淬火或火焰淬火更灵活；
- **重载齿轮**：渗碳淬火更常见，但要注意变形和磨齿。

### 再看失效模式

| 主要问题 | 优先考虑 |
| --- | --- |
| 齿面点蚀、接触疲劳 | 渗碳淬火、感应淬火、渗氮 |
| 齿根弯曲疲劳 | 保证芯部韧性，渗碳后齿根不应过度硬化 |
| 磨损、拉伤 | 感应淬火、渗氮、碳氮共渗 |
| 胶合 | 渗氮、提高表面硬度、降低粗糙度 |
| 变形敏感 | 渗氮、氮碳共渗、激光淬火 |
| 薄壁/细长件 | 控制加热和冷却均匀性，必要时校直 |

### 有效硬化层深度

工程上常用“到某一硬度值（如 550 HV）的深度”定义有效硬化层深度，而不是看金相总深度。设计时要区分：

- **总渗层深度**：从表面到芯部组织出现明显变化处；
- **有效硬化层深度**：从表面到规定硬度界限的深度；
- **化合物层/白亮层**：渗氮时表面形成的化合物层，过厚可能变脆。

不同标准、不同工艺的定义不同，图纸上应写明检测方法和界限硬度。

## 4. 结构设计要点

### 避免尖角、薄边和突然截面变化

感应淬火和渗碳淬火时，尖角、键槽、油孔和轴肩处容易：

- 过热、淬裂；
- 硬化层不均匀；
- 应力集中叠加；
- 磨削烧伤。

设计时应倒圆、加大过渡圆角，必要时对孔和键槽进行遮蔽或防渗处理。

### 控制变形

渗碳淬火变形较大，设计时要：

- 预留加工余量；
- 明确热处理后磨削的基准；
- 细长轴考虑校直和去应力；
- 齿轮考虑磨齿余量和热处理后精度；
- 薄壁件避免不对称布置。

### 芯部性能

表面硬、芯部韧是表面热处理的优势，但芯部硬度过低会导致硬化层失去支撑，出现压碎或剥落。要根据载荷确定芯部硬度范围，不能只写表面硬度。

### 磨削与表面完整性

热处理后磨削可能产生磨削烧伤、回火软化、残余拉应力。重要零件应：

- 控制磨削用量和冷却；
- 检查磨削烧伤（酸洗、硬度、金相）；
- 必要时进行喷丸，引入残余压应力；
- 避免在硬化层边缘磨削过深。

### 防渗与局部硬化

不需要硬化的部位（螺纹、键槽、油孔、配合面）可以：

- 镀铜防渗；
- 预留加工余量，热处理后切除；
- 局部感应淬火；
- 使用防渗涂料。

## 5. 常见失效与对策

| 失效 | 原因 | 设计/工艺对策 |
| --- | --- | --- |
| 硬化层不足、软点 | 加热不足、渗剂不足、材料淬透性差 | 控制工艺参数，检查层深和硬度，选合适材料 |
| 表层剥落 | 层深过大、表层过脆、芯部支撑不足 | 优化层深和硬度梯度，保证芯部硬度 |
| 淬火裂纹 | 尖角、截面突变、冷却过急、材料缺陷 | 加大圆角、控制冷却、预热、探伤 |
| 变形超差 | 加热/冷却不均、装炉方式不当 | 预留余量、对称装炉、校直、精加工 |
| 磨削烧伤/软化 | 磨削用量过大、冷却不足 | 控制磨削参数，检查烧伤，充分冷却 |
| 齿根疲劳 | 齿根过度硬化、残余拉应力、应力集中 | 控制齿根硬化层，喷丸，增大齿根圆角 |
| 渗层不均匀 | 气氛不均、局部防渗、装炉密集 | 改善气氛循环，合理装炉，检查层深 |

## 6. 检验与标准

常见检验：

- 表面硬度（HRC/HV）；
- 有效硬化层深度（硬度法、金相法）；
- 芯部硬度；
- 金相组织（马氏体、残余奥氏体、化合物层）；
- 变形量（圆跳动、直线度）；
- 裂纹（磁粉、渗透、超声）；
- 磨削烧伤。

标准检索线索：

- 渗碳和碳氮共渗：GB/T 3480.5、GB/T 9450、GB/T 9451；
- 感应淬火：GB/T 5617；
- 渗氮：GB/T 11354；
- 钢铁零件渗氮层深度测定和金相检验：GB/T 11354；
- 齿轮强度与材料：GB/T 3480 系列。

::: warning 以现行标准为准
标准号和适用范围会更新。正式设计时要核对现行版本，并在图纸上写清楚硬度、层深、检测位置和验收规则。
:::

## 7. 一个齿轮的例子

20CrMnTi 齿轮，要求齿面耐磨、齿根抗弯：

1. 渗碳淬火，有效硬化层深度取 0.8–1.2 mm；
2. 表面硬度 58–62 HRC，芯部硬度 30–45 HRC；
3. 渗碳后磨齿，保证齿形精度；
4. 齿根圆角处避免过度硬化，必要时喷丸；
5. 检查层深、硬度、金相和磨削烧伤；
6. 若齿轮精度要求很高，评估渗碳变形和磨齿余量。

如果换成 38CrMoAl 并采用渗氮，层深通常只有 0.1–0.5 mm，但变形小、抗胶合好。选择哪一种，取决于载荷、精度、批量和变形控制能力。
