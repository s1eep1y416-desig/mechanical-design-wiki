## 怎么用这张表

1. **先看章节**：公式不是孤立的，回到对应章节看失效形式和适用条件；
2. **再对单位**：转矩 N·mm、功率 kW、转速 r/min，是最容易出错的三处；
3. **最后看系数**：$K_A$、$K_v$、$K_\beta$、$Y_{Fa}$、$Z_E$ 等系数通常要查表，不能凭经验乱取。

::: warning 公式卡不是设计手册

:::

## 五个最常考的计算链

### 螺栓

```text
工作载荷 F → 总拉力 F₂ = F₀ + C_b/(C_b+C_m)·F
          → 残余预紧力 F₁ = F₂ − F
          → 应力 σ = 1.3F₂/A₁
          → 与 [σ] 比较
```

### 带传动

```text
功率 P、带速 v → 有效拉力 F_e = 1000P/v
             → 紧边/松边拉力 F₁、F₂
             → 最大有效拉力 F_ec
             → 根数 z、初拉力 F₀、压轴力 F_p
```

### 齿轮

```text
转矩 T₁ → 圆周力 F_t = 2T₁/d₁
       → 径向力 F_r、轴向力 F_a
       → 接触强度 σ_H、弯曲强度 σ_F
       → 与许用应力比较
```

### 滚动轴承

```text
径向/轴向载荷 → 当量动载荷 P = XF_r + YF_a
            → 寿命 L₁₀ = (C/P)^ε
            → L₁₀h = 10⁶/(60n)·L₁₀
```

### 轴

```text
功率 P、转速 n → 初估 d ≥ A₀(P/n)^(1/3)
             → 结构设计
             → 弯矩 M、转矩 T
             → σ_ca = √(σ_b² + 3(ατ)²)
```
