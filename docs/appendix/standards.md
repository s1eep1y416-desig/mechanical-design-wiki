# 国家标准与设计手册

<p class="page-lead">
机械设计不是只算公式：螺纹、键、齿轮、轴承、弹簧的尺寸和许用值，最终都要落到现行国家标准上。本页整理常用标准的检索线索，方便你从教材走向实际设计。
</p>

::: warning 使用前先核对版本
下表的标准号用于检索，标准会被修订或代替。正式设计、课程设计和考试引用时，必须以**现行有效版本**和最新设计手册为准。本页不转载标准正文。
:::

## 怎么查一个标准

1. **先确定对象**：螺纹、键、齿轮还是轴承；
2. **用标准号检索**：在国家标准全文公开系统输入 `GB/T 1096`；
3. **看标准状态**：确认“现行”，并查看是否被新标准代替；
4. **看适用范围**：同一标准可能只适用于特定规格或精度等级；
5. **回到教材/手册**：把标准中的尺寸、公差和许用值代回计算。

::: tip 标准和教材的关系
教材教你“为什么这样设计”，标准告诉你“具体取多少”。两者缺一不可。课程设计时，先按教材确定设计准则和计算式，再查标准选取标准件和公差。
:::
