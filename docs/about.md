# 关于本站

<p class="about-lead">
一个以《机械设计》（第十版）十八章为骨架的独立学习知识库。目标不是替代教材，而是把教材读薄、把知识连成网。
</p>

## 为什么做这个站

机械设计教材信息密度高，公式、表格、标准和工程经验交织在一起。传统笔记按页记录，复习时很难快速定位“这个公式防的是什么失效”“这个系数什么时候取大”。

本站尝试用类似 [OI Wiki](https://oi-wiki.org/) 的开放文档方式组织内容：

- 左侧按篇章导航，右侧显示本页目录；
- 全文搜索，支持关键词定位；
- 公式独立成卡，可复制 LaTeX；
- 每章附易错点与工程直觉，章节页标注教材页码，学习进度保存在本地；
- 疲劳曲线、极限应力图、Stribeck 曲线、螺栓力–变形图等 11 张图，按公式关系重绘为 SVG；
- 深浅色主题、移动端适配、打印样式。

## 内容结构

| 部分 | 内容 |
| --- | --- |
| 学习指南 | 使用方式、教材目录与页码、三条学习路线、符号约定 |

## 准确性说明

- 公式以通用机械设计教材体系为主，不同教材的符号和系数整理可能不同；
- 许用应力、寿命系数、载荷系数等必须查教材或手册，本站不提供完整表格；
- 典型材料参数仅为数量级参考，正式设计不能直接套用；
- 初版内容由人工整理并借助工具校对，仍可能存在错误。发现疑问时，请以正式教材、国家标准和设计手册为准。

::: warning 工程责任
本站仅供学习与复习使用。任何实际工程设计的强度、寿命、安全性和合规性，必须由具备资质的设计人员按现行标准和完整计算书确认。
:::

## 技术实现

- [VitePress](https://vitepress.dev/) 静态站点生成；
- Vue 3 自定义组件：章节导览、公式检索、学习进度；
- KaTeX 公式渲染；
- 本地全文搜索；
- 无后端、无账号、无追踪，学习进度只写入浏览器 `localStorage`。

- 转载或二次整理时注明来源与免责声明。
