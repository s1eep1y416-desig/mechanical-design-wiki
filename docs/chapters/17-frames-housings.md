> **一句话概括**：箱体设计的目标，是用合理的壁厚、肋板和支承结构，把载荷传到基础上，同时保证轴承孔的位置精度。

## 17.1 机座与箱体的功能

- **支撑**：安装轴、轴承、传动件和其他零部件；
- **定位**：保证各轴孔的中心距、平行度和同轴度；
- **承载**：承受传动件的作用力、转矩和倾覆力矩；
- **防护**：防止灰尘、切屑、水分进入，防止润滑油泄漏；
- **散热**：把齿轮、轴承和蜗杆产生的热量散出；
- **降噪**：通过结构阻尼和密封降低噪声。

## 17.2 材料选择

| 材料               | 优点                   | 缺点                 | 适用                 |
| ------------------ | ---------------------- | -------------------- | -------------------- |
| 灰铸铁 HT200/HT250 | 铸造性好、减振、成本低 | 强度较低、脆性大     | 大批量、形状复杂箱体 |
| 球墨铸铁           | 强度高、韧性好         | 成本较高             | 重载箱体             |
| 铸钢               | 强度高、韧性好         | 铸造性能差、需热处理 | 大型重载箱体         |
| 焊接钢结构         | 生产周期短、刚度高     | 残余应力、需退火     | 单件小批、大型机座   |
| 铝合金             | 轻、耐蚀               | 刚度低、成本高       | 轻量化、便携设备     |

选择材料时要考虑批量、载荷、刚度、减振、成本和制造周期。单件小批常用焊接结构，大批量复杂箱体常用铸铁。

## 17.3 结构设计要点

### 壁厚

壁厚要满足：

- 铸造工艺的最小壁厚；
- 强度与刚度要求；
- 螺纹连接和轴承座的局部承载；
- 散热与降噪。

壁厚过薄会产生浇不足、冷隔、变形；过厚则重量大、铸造应力大、冷却慢。箱体壁厚通常根据尺寸和材料查手册，并通过加强肋提高刚度，而不是单纯增加壁厚。

### 加强肋

加强肋的作用是提高截面惯性矩和局部刚度。布置原则：

- 肋应沿载荷传递方向布置；
- 避免肋与壁形成封闭的“死区”；
- 轴承座下方、箱体侧壁和底座是重点加强部位；
- 肋的厚度一般小于壁厚，避免收缩缺陷；
- 交叉肋应避免尖角，采用圆角过渡。

### 圆角与过渡

铸件壁与壁的连接处应设圆角，避免应力集中和铸造缺陷。圆角半径要与壁厚匹配，过小会开裂，过大会增加重量。

### 轴承座

- 轴承座应有足够的壁厚和刚度；
- 轴承孔两端应有加工余量和倒角；
- 同一轴上的两个轴承孔应一次装夹加工，保证同轴度；
- 轴承座附近布置加强肋；
- 考虑轴承的安装、拆卸和调整。

### 剖分面

剖分式箱体的剖分面通常通过轴心线，便于装拆。剖分面要：

- 有足够的宽度和刚度；
- 加工平整，保证密封；
- 用定位销保证重新装配时的位置精度；
- 布置足够数量的连接螺栓。

### 铸造工艺性

- 最小壁厚；
- 壁厚尽量均匀，避免热节；
- 起模斜度；
- 圆角过渡；
- 避免大面积水平面；
- 合理布置浇冒口；
- 减少加工面，尽量使加工面同一高度。

### 焊接工艺性

- 尽量减少焊缝数量和集中；
- 避免焊缝交叉；
- 采用对称焊接，减少变形；
- 焊后消除应力退火；
- 重要焊缝进行无损检测。

## 17.4 刚度设计

箱体的刚度通常比强度更重要。刚度不足会导致：

- 轴承孔中心距变化；
- 齿轮啮合偏斜，产生偏载；
- 轴系振动和噪声；
- 密封失效。

提高刚度的措施：

1. 合理布置加强肋；
2. 增大关键截面的惯性矩；
3. 缩短力流路径；
4. 采用封闭截面或箱形结构；
5. 提高轴承座局部刚度；
6. 避免悬臂和薄壁大跨度。

::: tip 刚度不等于强度
箱体可能强度足够，但刚度不足，导致轴承孔变形、齿轮偏载。设计时要区分“会不会坏”和“变形是否影响功能”。
:::

## 17.5 精度与工艺

- 选择统一的设计基准和工艺基准；
- 轴承孔、剖分面、底面要有合适的公差和表面粗糙度；
- 重要配合面需要刮研或磨削；
- 箱体加工后进行时效处理，消除内应力；
- 装配时用定位销、调整垫片保证位置精度；
- 考虑吊装、运输和安装地脚。

## 17.6 箱体设计检查清单

- □ 壁厚是否满足铸造/焊接工艺？
- □ 轴承座是否有足够刚度？
- □ 加强肋布置是否合理？
- □ 剖分面是否便于加工和密封？
- □ 定位销和连接螺栓是否足够？
- □ 润滑油路、放油孔、油标、通气器是否布置？
- □ 吊装、运输和安装是否方便？
- □ 加工面是否尽量集中？
- □ 是否考虑散热和降噪？

## 本章小结

- 箱体承担支撑、定位、承载、防护、散热和降噪功能；
- 材料选择要综合批量、载荷、刚度和成本；
- 壁厚、加强肋、圆角和轴承座设计决定箱体刚度；
- 铸造和焊接工艺性必须在结构设计阶段考虑；
- 箱体刚度不足会导致轴承孔变形和齿轮偏载。
