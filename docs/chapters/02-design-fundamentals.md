> **一句话概括**：先判断零件会怎样失效，再选择相应的设计准则，最后才是公式与尺寸。顺序反了，计算越精确越危险。

## 2.1 机器由什么组成

从功能角度看，一台机器通常包含五个部分：

| 组成部分 | 作用                       | 典型例子                     |
| -------- | -------------------------- | ---------------------------- |
| 原动机   | 提供动力                   | 电动机、内燃机、液压马达     |
| 传动装置 | 改变速度、转矩或运动形式   | 带传动、齿轮减速器、链传动   |
| 执行部分 | 完成工作任务               | 刀具、输送带、搅拌桨、机械手 |
| 控制系统 | 控制启动、停止、调速与安全 | 继电器、PLC、传感器          |
| 支撑结构 | 安装、定位并承受载荷       | 机座、箱体、立柱、导轨       |

机械设计课程主要处理**传动装置、连接和轴系零、部件**，以及它们与支撑结构的配合。控制系统和电气设计通常由其他课程承担，但机械结构必须为它们留出接口。

## 2.2 设计机器的一般程序

实际设计很少是“从零画图”，而是一个反复迭代的过程：

1. **明确需求**：功能、产量、精度、工作环境、寿命、成本；
2. **功能原理设计**：选择物理效应和运动方案，得到原理草图；
3. **总体方案设计**：确定传动链、功率流、主要尺寸和布局；
4. **技术设计**：计算传动件、轴、轴承、连接，完成结构设计；
5. **绘制图样**：零件图、装配图，标注尺寸、公差与技术要求；
6. **试制与试验**：验证强度、刚度、温升、噪声、寿命；
7. **改进定型**：根据试验和使用反馈修改设计。

::: tip 设计的“迭代”意味着什么
后面的计算可能推翻前面的方案。例如齿轮强度不够，可能需要增大中心距，从而改变箱体尺寸和轴的位置。因此不要过早把结构“画死”，要给关键尺寸留出调整空间。
:::

## 2.3 对机器的主要要求

- **功能要求**：能完成规定的工作，达到规定的生产率与精度；
- **可靠性**：在规定时间内、规定条件下完成规定功能；
- **安全性**：不发生危及人身或设备的失效；
- **经济性**：设计、制造、运行和维护成本合理；
- **工艺性**：零件可加工、可装配、可检测；
- **使用与维护性**：操作方便，易润滑、易更换易损件；
- **环境适应性**：耐温、耐蚀、防尘、低噪声、低振动。

这些要求往往互相制约。设计者的工作，是在具体约束下找到**综合最优**，而不是让某一项指标单独达到极限。

## 2.4 机械零件的主要失效形式

失效是指零件丧失了规定的功能。常见类型可以归为四组：

| 类型         | 具体形式                                   | 典型零件               |
| ------------ | ------------------------------------------ | ---------------------- |
| 整体破坏     | 静强度断裂、疲劳断裂、过载折断             | 轴、螺栓、轮齿         |
| 表面破坏     | 磨损、点蚀、胶合、腐蚀、接触疲劳           | 齿轮、轴承、导轨       |
| 变形与失稳   | 弹性变形过大、塑性变形、压杆失稳、弹簧失稳 | 轴、机架、细长杆       |
| 正常工作破坏 | 打滑、松动、泄漏、振动、噪声、温升过高     | 带传动、螺纹连接、密封 |

<DesignFigure id="failure-modes" />

### 失效分析的三要素

1. **载荷**：大小、方向、循环特性、冲击与分布；
2. **环境**：温度、介质、润滑、粉尘、腐蚀；
3. **结构**：几何突变、应力集中、配合、表面状态。

同一零件在不同工况下可能由不同失效形式控制。例如开式齿轮主要防磨损，闭式软齿面齿轮主要防点蚀，高速重载齿轮还要防胶合。

## 2.5 设计机械零件时应满足的基本要求

### 强度

强度是零件抵抗断裂或塑性变形的能力。静强度条件可写成：

$$
\sigma \le [\sigma]=\frac{\sigma_{\lim}}{S}
$$

其中 $\sigma_{\lim}$ 为极限应力（屈服极限或强度极限），$S$ 为安全系数。疲劳强度则要用疲劳极限和循环次数修正。

### 刚度

刚度是抵抗弹性变形的能力。条件为：

$$
y \le [y],\qquad \theta \le [\theta]
$$

机床主轴、精密丝杠、齿轮轴等对刚度要求很高，因为变形会直接影响加工精度或齿面接触。

### 寿命

寿命准则针对磨损、疲劳、腐蚀等随时间累积的失效。设计时要根据预期寿命确定许用应力或许用磨损量。

### 振动稳定性

为避免共振，零件的固有频率应避开激振频率。工程上常要求：

$$
f_p<0.85f \quad\text{或}\quad f_p>1.15f
$$

其中 $f_p$ 为零件固有频率，$f$ 为激振频率。

### 可靠性

可靠度 $R(t)$ 是零件在规定时间 $t$ 内正常工作的概率。若失效率 $\lambda$ 近似恒定：

$$
R(t)=e^{-\lambda t},\qquad \mathrm{MTBF}=\frac{1}{\lambda}
$$

## 2.6 机械零件的设计准则

设计准则是失效形式在计算上的“翻译”：

| 失效形式         | 设计准则       | 约束表达                             |
| ---------------- | -------------- | ------------------------------------ |
| 断裂、塑性变形   | 强度准则       | $\sigma\le[\sigma]$，$\tau\le[\tau]$ |
| 变形过大         | 刚度准则       | $y\le[y]$                            |
| 疲劳、磨损、腐蚀 | 寿命准则       | $L\ge[L]$ 或 $N\ge[N]$               |
| 共振             | 振动稳定性准则 | 固有频率避开激振频率                 |
| 功能失效概率过高 | 可靠性准则     | $R\ge[R]$                            |

::: warning 不要把所有问题都当成强度问题
带传动的打滑、螺栓的松动、滑动轴承的温升、轴的共振，都不是“应力超过许用值”那么简单。选错准则，公式再熟也没有意义。
:::

## 2.7 机械零件的设计方法

- **理论设计**：基于力学模型和失效判据，适用于载荷、材料、几何较明确的情况；
- **经验设计**：依据经验公式、类比和标准，适用于复杂或难以精确建模的场合；
- **模型试验设计**：通过缩比模型或样机试验确定参数；
- **现代设计方法**：有限元分析、优化设计、可靠性设计、计算机辅助设计、虚拟样机等。

现代设计方法并没有取代基础理论。有限元输入的本构、边界条件和载荷，仍然来自对失效形式的判断。

## 2.8 材料选择与标准化

### 材料选择要考虑什么

1. 力学性能：强度、塑性、韧性、疲劳强度、耐磨性；
2. 工艺性能：铸造、锻造、焊接、切削、热处理；
3. 环境性能：耐蚀、耐温、耐磨；
4. 经济性：材料价格、加工成本、供货周期。

<DesignFigure id="material-selection" />

### 标准化的意义

优先选用标准件、标准尺寸和标准公差，可以：

- 降低设计重复劳动；
- 保证互换性，便于维修；
- 降低制造成本和库存；
- 提高可靠性，因为标准件经过批量验证。

## 2.9 机械零件设计的一般步骤

1. 确定载荷与工作条件；
2. 选择材料与热处理；
3. 判断主要失效形式，选定设计准则；
4. 初算主要尺寸；
5. 结构设计，确定全部几何形状；
6. 精确校核强度、刚度、寿命；
7. 绘制零件图，标注尺寸、公差、表面粗糙度和技术要求。

## 本章小结

- 机器由原动机、传动、执行、控制和支撑结构组成；
- 设计是“需求 → 方案 → 计算 → 结构 → 试验 → 改进”的迭代过程；
- 常见失效分为整体破坏、表面破坏、变形失稳和正常工作破坏；
- 设计准则把失效形式转化为可计算的约束；
- 材料选择与标准化是设计不可分割的一部分。
