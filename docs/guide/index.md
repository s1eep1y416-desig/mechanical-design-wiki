# 使用指南

> 这不是教材的电子版，而是一套**按问题组织**的学习笔记。教材负责完整叙述，这里负责建立索引、压缩要点、暴露盲点。

> 需要对照纸质书页码时，打开 [教材目录与页码](/guide/textbook)。

## 这个知识库解决什么问题

《机械设计》第十版全书十八章、四百多页，内容横跨强度理论、连接、传动、轴承、轴系和整机设计。初学者最容易陷入两种状态：

- **按页读**：每一页都看懂了，合上书却串不起“为什么这样设计”；
- **背公式**：会套公式，但不知道适用条件、系数含义和失效对象。

这个站点把每章压缩成四个层次：

| 层次 | 你会看到 | 目的 |
| --- | --- | --- |
| 问题 | 本章要解决哪类工程问题 | 建立动机 |
| 模型 | 受力、失效形式、几何关系 | 知道公式从哪来 |
| 公式 | 核心计算式与符号说明 | 能算、知道边界 |
| 校核 | 易错点、工程直觉、关联章节 | 发现盲点 |

## 三种推荐读法

### 系统学习

从 [第 2 章 机械设计总论](/chapters/02-design-fundamentals) 开始，先掌握失效形式与设计准则，再按“连接 → 传动 → 轴系”的顺序推进。这是最稳的路径，适合第一次学这门课。

### 考前复习

打开 [核心公式速查](/appendix/formulas)，从螺栓、带、齿轮、轴承、轴五个高频计算模块反查知识点。每查一个公式，回到对应章节看适用条件和易错点。

### 课程设计

按 [学习路线中的课程设计路线](/guide/roadmap#课程设计路线) 推进：传动方案 → 电动机选择 → 传动件设计 → 轴系结构 → 轴承与箱体。不要先画图，先把传动比、功率和转矩流算清楚。

## 符号与单位

全书采用国际单位制。公式中常见符号：

- $T$：转矩，N·mm 或 N·m，代入强度公式时统一为 N·mm；
- $P$：功率，kW；
- $n$：转速，r/min；
- $d$：直径，mm；
- $\sigma$、$\tau$：正应力、切应力，MPa；
- $[\sigma]$、$[\tau]$：许用应力，MPa。

更完整的对照见 [单位、符号与换算](/appendix/units)。

::: tip 关于公式
页面中的公式用于梳理计算逻辑，不能替代教材中的图表、系数表和标准。实际设计时必须查取教材、国家标准或设计手册中的最新数据。
:::

## 内容边界

本站以《机械设计》（第十版）的**目录结构与知识框架**为参照，正文为独立撰写的学习笔记，不复制教材原文、例题和插图。教材中的标准表格、图表和完整推导，请以正式出版的第 10 版教材为准。

如果你发现公式、符号或表述有误，欢迎在后续接入仓库后提交修订。工程计算的正确性永远优先于排版。
