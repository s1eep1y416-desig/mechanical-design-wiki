# 教材目录与页码

<p class="page-lead">
本页把《机械设计》（第十版）的章、节和起始页码整理成索引，方便你在纸质书和本站之间来回对照。

## 怎么配合教材使用

1. **先看教材目录**：在本页展开对应章节，找到要读的小节和页码；
2. **再读本站笔记**：进入对应章节，先看“一句话概括”和失效分析，再回到教材精读推导；
3. **最后做对比**：教材中的图表、系数表和标准值，以书为准；本站负责把逻辑、公式和易错点压缩成可检索的条目。

::: warning 关于内容边界
本页只整理**目录标题和页码**，不复制教材正文、插图和例题。教材的完整内容请使用正版纸质书或出版社提供的数字课程。本站正文为独立撰写的学习笔记，不能替代教材。
:::
