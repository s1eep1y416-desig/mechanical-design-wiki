# 学习路线

> 不同目标需要不同的阅读顺序。下面给出三条路线，可以单独使用，也可以组合。

## 路线 A · 系统学习

适合第一次学习《机械设计》，或用它重建知识框架。

### 第一阶段：建立语言（第 1–4 章）

| 周次 | 内容 | 输出 |
| --- | --- | --- |
| 第 1 周 | 第 1–2 章：课程地图、失效形式、设计准则 | 能说出五种常见失效及对应准则 |
| 第 2 周 | 第 3 章：疲劳曲线、极限应力图、接触强度 | 会算简单疲劳安全系数 |
| 第 3 周 | 第 4 章：摩擦状态、磨损、润滑 | 能解释油膜形成条件 |

### 第二阶段：连接与传动（第 5–11 章）

| 周次 | 内容 | 输出 |
| --- | --- | --- |
| 第 4 周 | 第 5 章：螺纹连接 | 会算预紧螺栓的 $F_2$、$F_1$ 和强度 |
| 第 5 周 | 第 6–7 章：键、花键、焊接、过盈 | 会选择连接方式并校核 |
| 第 6 周 | 第 8–9 章：带、链传动 | 会做 V 带和滚子链的设计流程 |
| 第 7–8 周 | 第 10 章：齿轮传动 | 会做受力分析、接触和弯曲校核 |
| 第 9 周 | 第 11 章：蜗杆传动 | 会算几何、效率和热平衡 |

### 第三阶段：轴系与整机（第 12–18 章）

| 周次 | 内容 | 输出 |
| --- | --- | --- |
| 第 10 周 | 第 12–13 章：滑动/滚动轴承 | 会选轴承、算寿命、做轴系组合 |
| 第 11 周 | 第 14–15 章：联轴器、轴 | 会估轴径、做结构、弯扭校核 |
| 第 12 周 | 第 16–18 章：弹簧、箱体、减速器 | 能走通一台减速器的设计链 |

## 路线 B · 考前复习

适合已经学过一遍、需要快速找回计算能力。

### 第一步：锁定高频计算

1. **螺栓连接**：预紧力、总拉力、强度校核；
2. **带传动**：有效拉力、欧拉公式、应力、根数；
3. **齿轮传动**：受力、接触强度、弯曲强度；
4. **轴承**：寿命 $L_{10h}$、当量动载荷；
5. **轴**：轴径估算、弯扭合成；
6. **弹簧**：应力、变形、刚度。

### 第二步：用公式反查概念

打开 [核心公式速查](/appendix/formulas)，对每个公式问自己：

- 这个公式防止哪种失效？
- 各系数的物理意义是什么？
- 单位是什么？
- 适用条件是什么？

### 第三步：做三类题

| 题型 | 练习重点 |
| --- | --- |
| 选择/填空 | 失效形式、材料、标准、防松、润滑 |
| 简答 | 弹性滑动与打滑、提高疲劳强度措施、轴承组合 |
| 计算 | 螺栓、带、齿轮、轴承、轴 |

### 第四步：整理错题

每道错题至少记录：

1. 错在概念、公式还是单位；
2. 正确的失效判断；
3. 同类题的通用步骤；
4. 容易混淆的对照概念。

## 路线 C · 课程设计

以“带传动 + 两级圆柱齿轮减速器”为例，典型流程如下：

### 1. 传动方案

- 确定工作机功率、转速、工况；
- 选择电动机型号；
- 分配总传动比；
- 确定带传动和减速器的传动比。

### 2. 传动件设计

- 带传动：带型、带轮直径、中心距、根数；
- 高速级齿轮：材料、齿数、模数、中心距；
- 低速级齿轮：同理，注意浸油深度；
- 蜗杆传动（如采用）：效率、热平衡。

### 3. 轴系设计

- 初估各轴直径；
- 布置轴上零件，确定轴向定位；
- 选择轴承类型和型号；
- 校核轴的弯扭合成和疲劳；
- 校核键连接。

### 4. 箱体与附件

- 确定箱体壁厚、加强肋、轴承座；
- 设计剖分面、定位销、连接螺栓；
- 布置油标、放油塞、通气器；
- 选择密封和润滑方式。

### 5. 校核与绘图

- 热平衡、寿命、安全系数；
- 装配图、零件图；
- 公差、表面粗糙度、技术要求；
- 设计说明书。

::: tip 课程设计的顺序不能反
不要先画装配图再补计算。正确顺序是“方案 → 计算 → 结构 → 校核 → 绘图”。计算决定了中心距、轴径和轴承型号，结构只是把它们组织起来。
:::

## 一张全局路线图

```text
需求与工况
   ↓
电动机选择 → 总传动比分配
   ↓
带/链/齿轮/蜗杆设计 → 轴径初估
   ↓
轴系结构 → 轴承选型 → 键/联轴器
   ↓
箱体与附件 → 润滑/密封/散热
   ↓
强度、寿命、热平衡校核
   ↓
装配图 / 零件图 / 说明书
```

## 每天 30 分钟怎么学

- **10 分钟**：读一节概念，合上书用自己的话复述；
- **15 分钟**：手推一个公式或做一道计算；
- **5 分钟**：合上笔记，复述本章的一条计算链。

坚持两周，你会发现自己不再“看什么都懂、做题都不会”。
